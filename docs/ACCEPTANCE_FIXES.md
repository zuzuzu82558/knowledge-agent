## 升级与边界

1. 重启应用后，旧 generation 唯一约束会事务迁移；迁移前备份 `state.pre-rebuild-v3.sqlite3`。本次仅在隔离数据上执行迁移验证。
2. 解析契约升级为 `m5-v3-html-dom-table-grid`。旧索引在界面点击“重建索引”后可用于新规则查询，旧引用仍保留。不要删除业务数据目录升级。当前配置下重建失败保留原可查询代次；跨配置的旧索引仍受原有兼容性门禁限制。
3. 下载源 HTML 使用附件与 octet-stream，不在应用同源执行；原文页面是可读抽取块和位置，非 PDF/Office 原生页内高亮预览。
4. 当前历史入口最多 50 条，从最近 200 条中筛选可用记录，没有分页与全文搜索。表格仍不保证复杂排版与所有合并单元格语义完整，无 OCR。
